# Zombie vs Home

A small browser game where you protect your home from relentless zombie waves.

## How to play

- Move with WASD or Arrow Keys
- Aim with the mouse
- Click to shoot
- Survive as long as possible
- The home loses health when a zombie reaches it
- Press `R` after a game over to restart

## Run locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Project files

- `index.html` — page layout and HUD
- `style.css` — game styling
- `game.js` — gameplay logic

## Goal

Defend your home and keep the zombie horde away for as long as possible.
